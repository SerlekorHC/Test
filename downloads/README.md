# Downloads

This folder is a placeholder for the Fedora installation media.

## Download the official ISO

Use the official Fedora Xfce Live x86_64 ISO from Fedora Spins:

- https://spins.fedoraproject.org/xfce/download/index.html

## Expected SHA256

Use the x86_64 Live ISO and verify the file hash against:

```text
55ea8cb52ac16e62f436e37f9fdb4e978d7b9f75814a9d42e8b69d05e3b496ad
```

## Recommended filename

```text
Fedora-Xfce-Live-x86_64-44.iso
```

Place the ISO here after download if you are using this repo as a local project folder.

## Why this folder exists

The repo documents the boot process, but the ISO itself is too large to store in git and should be downloaded directly from Fedora.
